# WVview
Single Page WireViz Viewer supporting .gv imports from Wireviz meant for navigating large harnesses and making sub-diagrams, hiding nodes and associated wires, highlighting nodes and connectivity, adjusting horizontal and vertical spacing, supporting images, and exporting a png/svg with all your tweaks.

Github Pages version Served at https://teddyphoenixboring.github.io/WVview/

Fully AI Coded for my own use on large cable harness drawings, use at your own risk.
